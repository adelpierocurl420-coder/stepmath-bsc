# 60-second judge demo

1. **0:00 Home.** Judge strip shows the login. Hero stats show data is preloaded. Search `robot`, then filter category Quiz.
2. **0:10 Event.** Open AI Web Development Contest: deadline, live countdown, 6 seats left, announcement. Open Gaming Tournament: full, form says Join waitlist.
3. **0:20 Register.** Submit an empty form to see errors, then fill it in. Ticket appears with REG ID and QR.
4. **0:30 My Registrations.** Enter the same email, edit your name, open View ticket.
5. **0:40 Organizer.** Open Organizer, tap One-tap demo login (admin / admin123). Show KPIs, 7-day chart, fill bars.
6. **0:50 Participants.** Search your REG ID, change status. Filter Gaming + confirmed, set one to cancelled: the waitlisted person is promoted.
7. **0:57 Check-in.** Paste your REG ID or email, tap Mark checked in.
